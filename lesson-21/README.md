# Lesson 21 — JavaScript ES6+ Basics

## Overview

This lesson introduces modern JavaScript syntax and features commonly used in contemporary web development.

## Topics Covered

- Arrow functions
- Template literals
- Array destructuring
- Object destructuring
- Spread operator
- Rest operator
- Default parameters
- Combining arrays and objects
- Real-world developer and job examples

## How to Run

```bash
node script.js
```

## Practice Challenges

1. Create an arrow function for subtraction.
2. Print a sentence using template literals.
3. Destructure an array of skills.
4. Destructure a job object.
5. Combine two arrays with spread syntax.
6. Calculate a total using rest parameters.
7. Create and update a developer object.

## What I Learned

I learned how ES6+ syntax can make JavaScript code more concise and easier to work with.
