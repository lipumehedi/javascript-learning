# Lesson 22 — JavaScript Advanced Array Methods

## Overview

In this lesson, I practiced advanced JavaScript array methods using developer skills, salary data, and job listings.

## Topics Covered

- `forEach()` — perform an operation for each item
- `map()` — transform items into a new array
- `filter()` — select items that match a condition
- `find()` — find the first matching item
- `some()` — check whether at least one item matches
- `every()` — check whether all items match

## Real-World Practice

- Display developer skills
- Transform numbers and strings
- Filter adults and backend skills
- Find a developer by skill
- Filter jobs by salary
- Extract job titles
- Check job locations and salary conditions

## How to Run

```bash
node script.js
```

## Practice Challenges

1. Use `forEach()` to display every skill.
2. Use `map()` to calculate the square of each number.
3. Use `filter()` to select salaries of ¥5,000,000 or more.
4. Use `find()` to locate a Python developer.
5. Use `some()` to check whether any job pays at least ¥5,000,000.
6. Use `every()` to check whether all students scored at least 60.
7. Create a job array and practice all six methods.

## What I Learned

I learned how to process arrays efficiently using modern JavaScript methods and apply them to developer data and job listings.
