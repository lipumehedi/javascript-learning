# JavaScript Lesson 18 — Forms and Validation

## Overview

In this lesson, I learned how to handle HTML form submissions and validate user input using JavaScript.

## Topics Covered

- HTML forms and input fields
- `submit` event
- `addEventListener()`
- `event.preventDefault()`
- Input `.value`
- `trim()` and `length`
- Email validation with the browser's built-in validity check
- Conditional validation with `if` statements
- Error and success messages
- `form.reset()`

## Project

A simple registration form that validates a user's name, email, and password before showing a success message.

## Folder Structure

```text
lesson-18/
├── index.html

```

## How to Run

1. Open `index.html` with VS Code Live Server.
2. Enter your name, email, and password.
3. Click Register.
4. Test both invalid and valid inputs.

## Practice Challenges

1. Require at least three characters in the name.
2. Add a Confirm Password field.
3. Show an error if both passwords do not match.

## What I Learned

I learned how to respond to form submissions, stop the browser's default page reload, validate user input, and show feedback to users.
