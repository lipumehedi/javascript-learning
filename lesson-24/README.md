# Lesson 24 — JavaScript Modules

## Overview

In this lesson, I learned how to organize JavaScript code into separate modules using `export` and `import`.

## Topics Covered

- JavaScript modules
- Named exports
- Named imports
- Default exports
- Default imports
- Importing functions and constants
- Reusing code across multiple files
- Browser modules with `type="module"`

## Project Structure

```text
lesson-24/
├── index.html
├── script.js
├── math.js
├── developer.js
└── README.md
```

## How to Run

1. Open `index.html` with VS Code Live Server.
2. Open the browser Developer Tools.
3. Select the Console tab to view the output.

## Practice Challenges

1. Add a `power()` function to `math.js` and import it into `script.js`.
2. Create a `greet()` function in a new `greetings.js` file.
3. Export and import a constant named `country`.
4. Add a new skill to the developer module.
5. Create a salary calculator in a separate module.

## What I Learned

I learned how to split JavaScript code into reusable modules and import functions, constants, and objects from other files.
