# Lesson 25 — JavaScript Promises

## Overview

In this lesson, I learned how JavaScript Promises represent the eventual success or failure of asynchronous operations.

## Topics Covered

- Promise
- Pending, fulfilled, and rejected states
- `resolve()` and `reject()`
- `.then()` for handling successful results
- `.catch()` for handling errors
- `.finally()` for cleanup after settlement
- `setTimeout()` for simulating a delay
- Promise chaining
- Working with developer data

## Real-World Practice

- Handle successful and failed operations
- Check student scores with a Promise
- Simulate loading developer information
- Process values through a Promise chain

## How to Run

1. Open `index.html` with VS Code Live Server.
2. Open the browser Developer Tools.
3. Select the Console tab to view the output.

## Practice Challenges

1. Create a Promise that resolves with your name.
2. Create a Promise that rejects with an error message.
3. Write a function that resolves when a score is at least 60.
4. Simulate loading job information after a short delay.
5. Use `.then()`, `.catch()`, and `.finally()` together.
6. Chain two calculations using multiple `.then()` calls.

## What I Learned

I learned how to handle asynchronous results and errors using JavaScript Promises.
