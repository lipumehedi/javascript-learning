# Lesson 26 — JavaScript Async/Await

## Overview

In this lesson, I learned how to work with asynchronous JavaScript using `async`, `await`, and `try/catch`.

## Topics Covered

- Async functions
- Awaiting Promises
- Returning values from async functions
- Error handling with `try/catch`
- Simulating asynchronous operations
- Running tasks in sequence
- Working with developer and job data

## Project Structure

```text
lesson-26/
├── index.html

```

## How to Run

1. Open `index.html` with VS Code Live Server.
2. Open the browser Developer Tools.
3. Select the Console tab to view the output.

## Practice Challenges

1. Create an async function that returns your name.
2. Use `await` to retrieve a message from a Promise.
3. Create a function that checks whether a score is at least 60.
4. Handle a rejected Promise using `try/catch`.
5. Simulate loading job information after a short delay.
6. Run two asynchronous tasks in sequence.

## What I Learned

I learned how `async` and `await` make asynchronous JavaScript easier to read and how `try/catch` helps handle errors.
