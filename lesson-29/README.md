# Lesson 29 — JavaScript Error Handling

## Overview

This lesson demonstrates how to handle errors safely in JavaScript using try/catch/finally, custom errors, JSON parsing, and API requests.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Error Handling
- Fetch API
- JSON

## Topics Covered

- `try` and `catch`
- `throw new Error()`
- `finally`
- `error.message`
- Input validation
- JSON parsing errors
- HTTP response validation
- API error handling with async/await

## Project Structure

```text
lesson-29/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Features

- Division calculator with input validation
- Division-by-zero error handling
- Valid and invalid JSON parsing examples
- API data loading with error handling
- Loading and completion states

## How to Run

1. Open the project in VS Code.
2. Open `index.html` using Live Server.
3. Test the division calculator.
4. Try both JSON buttons.
5. Click Load User to test the API request.
6. Open the browser console with F12 to inspect errors and logs.

An internet connection is required for the API example.

- How to catch and handle JavaScript errors
- How to create custom errors
