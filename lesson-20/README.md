# JavaScript Day 20 — Developer Task Manager

## Overview

A small task management application built with HTML, CSS, and JavaScript.

This project combines the JavaScript fundamentals learned in Lessons 1–19.

## Features

- Add tasks
- Mark tasks as completed
- Delete individual tasks
- Clear completed tasks
- Display total, completed, and remaining task counts
- Save tasks in browser Local Storage
- Restore tasks after a page refresh
- Responsive layout for smaller screens

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- Arrays and Objects
- Array Methods
- JSON
- Local Storage

## How to Run

1. Open the project in VS Code.
2. Open `index.html` with Live Server.
3. Add a task using the input field.
4. Mark tasks as completed or delete them.
5. Refresh the page to test Local Storage persistence.
