# Day 30 — Developer Job Tracker

## Overview

Developer Job Tracker is a JavaScript capstone project for managing job applications. Users can add applications, update their status, search and filter records, and save their data in browser Local Storage.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Event Listeners
- Array Methods
- Fetch API
- Async/Await
- JSON
- Local Storage
- Error Handling

## Features

- Add job applications
- Track Applied, Interview, Offer, and Rejected statuses
- Search by job title, company, or location
- Filter applications by status
- Delete applications
- Display dashboard statistics
- Persist data using Local Storage
- Load sample records from a public demo API
- Handle API errors and invalid input
- Responsive layout

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html` using Live Server.
3. Add a job application using the form.
4. Update its application status.
5. Search and filter your applications.
6. Refresh the page to verify Local Storage persistence.
7. Click Load Demo Data to test the Fetch API.

An internet connection is required for the demo data feature.

## API

JSONPlaceholder public demo API:

https://jsonplaceholder.typicode.com/users

The returned user data is transformed into fictional sample job records for practice. These records are not real job vacancies.
