# Lesson 23 — Advanced Objects and Destructuring

## Overview

In this lesson, I practiced advanced JavaScript objects, destructuring, and modern syntax using developer profiles, API responses, and job listings.

## Topics Covered

- Object destructuring
- Renaming properties
- Default values
- Nested object destructuring
- Array destructuring
- Rest operator
- Spread operator
- Copying and merging objects
- Optional chaining
- Working with nested API data

## Real-World Practice

- Extract developer profile information
- Read nested job details
- Copy and update objects
- Merge personal and technical information
- Access nested API response data safely
- Extract job requirements

## How to Run

```bash
node script.js
```

## Practice Challenges

1. Create a student object and destructure its properties.
2. Rename an object's `name` property to `studentName`.
3. Use a default value for a missing country property.
4. Destructure a nested company object.
5. Extract the first two skills from an array and collect the remaining skills.
6. Copy a developer object and add a `database` property.
7. Merge two objects into one profile.
8. Use optional chaining to access a possibly missing email address.

## What I Learned

I learned how to extract, rename, copy, merge, and safely access JavaScript object data using modern syntax.
